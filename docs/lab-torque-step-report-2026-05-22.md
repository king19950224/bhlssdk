# 实验室 M20×80 扭矩阶梯验证报告

> 日期：2026-05-22  
> 对象：实验室 M20×80 螺栓  
> 设备：device 1 / channel 9  
> 目的：验证扭矩变化与超声声时变化是否具备稳定、可重复、近似线性的响应  
> 结论级别：工程验证，不作为正式载荷标定

| 项 | 值 |

| 螺栓规格 | M20×80 |
| 通道 | device 1 / channel 9 |
| 探头频率 | 2 MHz |

| 阈值 | `Threshold=-490` |

说明：扭矩法估算受螺纹、端面摩擦、润滑、垫片状态影响很大。本报告只用于判断超声响应是否稳定，不作为最终预紧力验收结论。

## 5. 线性拟合

拟合口径：

- 横轴：扭矩法估算预紧力 `F`
- 纵轴：温补声时差 `Δt`
- 排除污染点 ID=3

拟合结果：

| 指标 | 值 |
|---|---:|
| 有效点数 | 6 |
| 临时 K_L | `0.001427963 ns/N` |
| 截距 | `49.7616 ns` |
| R² | `0.995596` |
| 扭矩范围 | 50~200 N·m |
| Δt 范围 | 67.8456~121.1693 ns |

当前已应用为系统 active calibration：

| 项 | 值 |

应用后实时数据验证（2026-05-22 13:04）：

| 指标 | 值 |
|---|---:|
| 最近 2 分钟样本 | 1200 |
| EchoTime 接受率 | 100% |
| 平均预紧力 | 49.14 kN |
| 平均 ratio | 0.983 |
| algo_version | `phase1:TorqueFitSingleWave:1.0.0` |

解释：

- R² 接近 1，说明在本次实验条件下，扭矩估算预紧力与超声 Δt 呈较好线性关系。
- 截距不为 0，说明当前 RefTime 并不是严格零载荷参考点，或者扭矩法估算存在系统偏差。
- `K_L=0.001427963 ns/N` 只能视为扭矩法工程拟合值，不等同于载荷标定 K_L。

## 6. 结论

本次实验可以支持以下判断：

1. 真实设备链路已经跑通，EchoTime 可稳定输出。
2. 探头/耦合/螺栓状态具备可观测的声时响应。
3. 50~200 N·m 范围内，超声 Δt 与扭矩估算预紧力关系较线性。
4. 当前扭矩法临时标定可用于演示趋势、验证系统闭环、做现场调试。

不能支持以下结论：

1. 不能认定真实轴向预紧力就是 50 kN。
2. 不能作为安全验收或正式工程报警阈值依据。
3. 不能替代 GB/T 43232-2023 要求的正式标定流程。

## 7. 下一步

建议下一阶段做一组正式标定：

1. 使用拉伸机、载荷垫圈或已知载荷工装；
2. 做至少 5 个载荷点；
3. 每点保持 60 秒；
4. 拟合 `Δt-F`；
5. 按 JJF 1059.1 做不确定度；
6. 替换当前 `torque_estimate` 标定记录。

在正式标定前，系统界面和报告必须标注：

> 当前预紧力为扭矩法临时估算，未做载荷标定。
