## 1. 页面功能总清单（17 页）

### 1.1 监测运营组

**总览 Dashboard（`/`）** — 全站预紧力健康总览
- 功能：安全结论（verdict）、待处置磁贴（跳告警/资产/设备）、健康分布、残压分布、24h 保持率趋势、最松螺栓/即将到限列表、按部位健康条
- 实时：OnAlarm + OnMeasurement（5s 去抖）+ 30s 轮询；权限：全部登录用户
- 交付检查：
  - [ ] verdict 口径与告警中心一致（无"总览绿灯、告警未闭合"的自相矛盾）
  - [ ] 空库/无标定/无测量三种状态下不出 NaN、不白屏
  - [ ] 磁贴跳转目标页筛选条件正确带过去

**实时波形 LivePreload（`/live`）** — 多通道实时预紧力波形
- 功能：kN/保持率%切换、时间窗 2/5/10 分、平滑/原始、暂停/恢复、通道多选
- 实时：OnMeasurement + 2.5s 轮询；权限：全部
- 交付检查：
  - [ ] **热插拔全通道轮询后单通道刷新率约 4s/条，确认波形不断线、不误显示"无数据"**（与标定页同源的稀释问题）
  - [ ] 客户端换算与后端 preload_n 一致（抽 1 个点对数）
  - [ ] 长时间挂后台再切回，内存/曲线正常

**资产监测 AssetMonitor（`/assets`）** — 风场→风机→部位→螺栓分层
- 功能：多项目切换、搜索、法兰布置图/趋势对比/网格（最危险优先）、配置孔位数、敲击识别入口、建档绑定、未绑定通道提示、法兰验收报告生成（复核员）
- 实时：OnAlarm + 螺栓层 OnMeasurement；权限：报告生成需 reviewer
- 交付检查：
  - [ ] 法兰布置图孔位号与现场位号对得上（含未监测孔位显示）
  - [ ] 空项目/空风机的降级显示
  - [ ] 验收报告数字与详情页一致

**螺栓详情 BoltDetail（`/bolts/:id`）** — 单螺栓档案与操作中枢
- 功能：KPI、实时 A-Scan、趋势（1h/24h/7d）、温度叠加、设基线（复核员）、预紧力设置编辑、超声参数调整→审批、标定向导入口、标定会签（禁自签）、履历时间线
- 实时：OnMeasurement + 4s 轮询兜底；权限：写操作 reviewer
- 交付检查：
  - [ ] 趋势 1h/24h/7d 三档桶粒度正确、最新段不缺（曾修过 ASC+LIMIT 丢最新的 bug，回归确认）
  - [ ] A-Scan 检出点/RefTime/ΔTOF 与波形诊断页同源一致
  - [ ] 会签按钮对提交人本人禁用且后端 400 兜底
  - [ ] 预测（prediction）在样本不足时显示"数据不足"而非误导性外推

**告警中心 Alarms（`/alarms`）** — 告警处置与抑制
- 功能：未闭合/未确认/已闭合/全部四视图、确认、闭合（填原因）、批量确认、维护抑制（按时长/类型/整螺栓）、取消抑制
- 实时：OnAlarm + 30s 轮询；权限：全部登录用户
- 交付检查：
  - [ ] 触发→确认→恢复→闭合全链路状态机走一遍（含 preload_low 回差与 on/off-delay）
  - [ ] 抑制生效期间 signal_lost 确实被拦（换探头场景）
  - [ ] 提示音开关持久化、批量确认审计留痕

### 1.2 计量与变更组

**标定中心 Calibration（`/calibration`）** — ✅ 已深检
- 功能：方法/可信级摘要卡、螺栓标定花名册、标定向导（新装两步法/在役趋势基准）、专家模式（快速/扭矩法/扭矩阶梯/正式载荷/档案会签驳回）
- 权限：页面 reviewer+；会签异人后端强制
- 交付检查（余项）：
  - [ ] 真机走一遍向导全流程（零载基线→拧紧→扭矩→出预紧力）
  - [ ] 正式载荷标定提交→另一账号会签→生效，全链路
  - [ ] 过期标定的螺栓在详情页不出"正式"预紧力（IsUsableForOfficialPreload 口径）

**参数审批 ConfigChanges（`/config-changes`）** — 超声参数双人复核
- 功能：待办/全部、详情、审批、驳回（填原因）、执行下发、读回验证
- 轮询 8s；权限：审批需 reviewer 且审批人≠提交人
- 交付检查：
  - [ ] 提交→审批→下发→读回验证全链路真机走通
  - [ ] 下发失败（设备离线）的状态与重试路径
  - [ ] 扫描/标定进行中下发被 409 拒绝的提示可读

### 1.3 设备与诊断组

**采集设备 Devices（`/devices`）** — ✅ 已深检（含热插拔）
- 功能：设备卡片、通道健康、工作模式下发（复核员）、重标定基线、通道自动检测（发起/中止/进度）、通道绑定/解绑、热插拔实时在位（OnChannelPresence）
- 交付检查（余项）：
  - [ ] 真机热插拔验证清单（插新探头→秒级弹通道号→未绑定列表→人工绑定；拔出→20s 显示断开→120s signal_lost）
  - [ ] 全通道轮询下发日志确认 + 扫描后 MCR 恢复确认

**通道识别 ChannelIdentify（`/identify`）** — 敲击识别与位号标注
- 功能：1s 刷新跳动高亮、输入位号标注、跳转详情
- 交付检查：
  - [ ] **热插拔轮询稀释后单通道 4s 一条，确认"敲击高亮"响应仍可用**（该页设计前提是高频刷新，最可能受影响）
  - [ ] 位号标注写入后资产页/法兰图同步

**波形诊断 Diagnostics（`/diagnostics`）** — A-Scan 对比与信号质量
- 功能：实时开关、跟随最新、设/更新参考基线、特征表切通道、健康度/相似度/衰减/ΔTOF
- 轮询 1.5s；权限：reviewer+
- 交付检查：
  - [ ] 真机 MultiMeas 不随测带波形——确认 WaveSampling 开关关闭时页面的降级提示（数据源是补采的 LEchoWave）
  - [ ] 参考基线更新后相似度立即重算

### 1.4 治理组

**审计日志 Audit（`/audit`）** — 权限 reviewer+
- 功能：按动作/时间查询、分页、CSV 导出
- 交付检查：
  - [ ] 抽查关键动作都有审计：标定、会签、驳回、下发、解绑、用户管理、告警闭合
  - [ ] CSV 中文不乱码

**报告 Reports（`/reports`）+ 报告详情（`/reports/:id`）**
- 功能：类型筛选、下载、扭矩阶梯报告生成（复核员）、详情快照展示、审核签发（签发人≠编制人）、导出 PDF/打印
- 交付检查：
  - [ ] 两类报告（法兰验收/扭矩阶梯）各生成一份，数字与页面一致
  - [ ] 签发异人约束后端兜底确认
  - [ ] 下载文件的路径逃逸防护回归（reports/file_url）

**用户管理 Users（`/users`）** — 权限 admin
- 功能：新建用户、重置密码、启停（不可停自己）
- 交付检查：
  - [ ] 最后一名 admin 不可停用/降级（已有集成测试，真机点一遍）
  - [ ] 密码错误锁定（failed_attempts/locked_until）生效
  - [ ] 停用用户的旧 token 立即失效（token_version）

### 1.5 独立页面

**登录 Login（`/login`）**
- 交付检查：

  - [ ] 登录后跳转 `r` 参数只允许站内路径

**态势大屏 BigScreen（`/board`）**
- 功能：健康饼图、部位条、告警滚动、最松/即将到限、设备状态、时钟
- 交付检查：
  - [ ] 工控机目标分辨率（现场大屏）下布局不溢出
  - [ ] 7×24 挂机 24h 无内存泄漏/卡顿（可先 2h 抽测）

## 2. 深检推进顺序（建议）

按"安全攸关 → 数据正确性 → 操作流 → 展示"排序，每页照标定页的深检方法过：

1. [ ] **Alarms 告警中心**（安全攸关：状态机、抑制、批量操作）
2. [ ] **BoltDetail 螺栓详情**（数据中枢：趋势口径、会签、参数审批入口）
3. [ ] **Dashboard 总览 + BigScreen 大屏**（对外第一印象：verdict 口径一致性）
4. [ ] **ConfigChanges 参数审批**（双人复核闭环 + 设备下发）
5. [ ] **LivePreload + ChannelIdentify**（重点：热插拔轮询稀释的影响面）
6. [ ] **AssetMonitor + Reports/ReportDetail**（法兰图位号、报告数字一致性）
7. [ ] **Diagnostics 波形诊断**（依赖 WaveSampling 数据源的降级路径）
8. [ ] **Audit + Users + Login**（治理面，条目少，半天内）

## 4. 交付硬缺口（阻塞项）

1. [ ] **Windows 安装包**：`deploy/installer/` 仍为空，README 承诺 Inno Setup 安装（工控机无 Docker，PG 原生二进制）。要么补安装器，要么改交付方式并同步文档。**这是目前最大的交付缺口。**
2. [ ] **生产配置定稿**：`Fx:Real:CommParams`（现为 192.168.0.7:23）、`Jwt__SigningKey`、License 公钥、数据库连接串的现场注入清单。
3. [ ] **未提交代码**：标定页深检修复（当前工作区）需提交；决定 v1.0.0 是否重打（含热插拔 + 标定修复）或升 v1.1.0。
4. [ ] **真机回归**：热插拔与标定修复都改了采集/标定主路径，交付前必须在实验室真机完整跑一轮 §1 各页实测项。
