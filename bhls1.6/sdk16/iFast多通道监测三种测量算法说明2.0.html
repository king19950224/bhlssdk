多通道监测平台三种测量方法与长期监测选型指南

多通道监测平台提供自动（Beta）、动态特征和阈值三种测量方法。 本文说明三种方法如何确定测量点、各自适合的波形和现场条件，以及出现异常时应重点检查的内容。

阅读建议：选择方法时先看“模式总览”和各方法的“适用场景”；现场调试时重点观察主回波区域、辅助定位点和连续多帧结果。 三种方法使用相同的基础波形预处理，差别主要在于如何从目标回波中确定最终测量位置。

长期监测如何选择

先明确一个原则：三种方法都只是从回波中确定声时测量点，并不改变螺栓的标定关系。 在弹性工作区间内，轴力通常按 F = c1 × Δt + c0 由声时差换算；方法选得是否合适，决定的是 Δt 能否长期、连续地代表同一个物理回波。正确结果应随加载和卸载连续变化，并与轴力保持单调、近似线性的关系。

客户选型顺序

确认设备能力

设备若只支持阈值法，按阈值法配置；支持三种方法时继续判断波形。

先看主回波

有稳定多周期回波包，优先试自动法；只有陡峭起始边沿，可试阈值法。

再看长期变化

预期载荷、温度和回波位置变化较大时优先自动法；只看包络趋势时可选动态特征法。

用试验确认

加载、卸载并改变温度，比较连续性、单调性、重复性和无效率后再定型。

探头粘贴与耦合劣化的共同边界

有数值不代表粘贴正常：探头轻微松动或局部脱粘时，自动法和动态特征法可能仍能从残余回波中得到连续、看似合理的声时差； 这只是算法仍能定位回波，并不能证明该回波仍稳定代表螺栓轴力。随着脱粘扩大，回波幅值会下降、包络和相位会变形，最终三种方法都会输出无效结果或无数据。
粘贴状态可能看到的波形和数据三种方法的典型表现处理原则
轻微劣化 幅值缓慢下降，噪声增大，波形形状略有变化；声时差暂时仍连续 自动法和动态特征法通常仍可给出数值；阈值法只要仍越过阈值也可能正常 不能仅看轴力曲线，应同时检查峰值、信噪比、波形形状和无效率
部分脱粘 主回波明显衰减或变形，可能出现替代回波；结果可漂移、跳变或间歇无效 自动法可能改选其他回波包；动态特征法的包络前沿可能漂移；阈值法可能跌破阈值或命中干扰 将数据标记为质量异常并触发维护预警，不应继续作为可靠轴力依据
完全脱落 有效回波消失，只剩噪声或极弱信号 三种方法均应进入信号过弱、未命中或特征定位失败状态，不再产生有效轴力 检查探头、胶层、线缆和接口，重新处理粘贴后必须重新扫波、置零和验证

长期系统应把“轴力结果”和“信号质量”分开监控。建议至少记录峰值、有效/无效状态、连续无效次数和波形质量变化； 当轴力看似平稳但峰值持续下降或波形明显变形时，应优先判断为探头或耦合异常，而不是认为结构状态稳定。

1. 自动（Beta）：包络粗定位 + 上升沿过零定位

自动法先根据主回波包络确定大致位置，再将最终测量点落在真实波形的上升沿过零点上。 首次扫波不需要已有参考值；完成置零后，系统保存 F0/Z0/T0，并在测量和监测过程中根据包络位移预测目标过零位置。 因此，即使回波相对置零波形移动了一个或多个周期，算法仍可在预测位置附近选择同相上升沿。

工作过程

  1. 首先检查信号是否达到有效幅值要求；信号过弱时，本帧结果判定为无效。
  2. 去除直流偏置并计算回波包络，再根据峰间距离、谷底深度、峰值比例和能量比例合并属于同一回波包的相邻峰。
  3. 综合回波能量、有效周期数和出现位置选择主回波，三项权重分别为 50%、30% 和 20%。
  4. 以主回波包络峰值的 30% 作为动态阈值，并通过插值得到包络粗定位点 Fx。
  5. 在主回波高能量区统计相邻上升沿的间距，使用中位数和中位数绝对偏差（MAD）估算实际载波周期。至少需要 3 个稳定周期间距，离散程度不得超过中位周期的 15%。
  6. 周期按 T0 → 当前实测周期 → 探头配置周期 的顺序选用。实测周期还应处于配置周期的 60%～140% 范围内；无法得到可靠周期时，本帧结果判定为无效。
  7. 首次扫波或没有 F0/Z0 时，只接受 Fx 之后 0.8 个周期内的第一个合格上升沿过零点。
  8. 已有 F0/Z0 时，按 Z预测 = Z0 + (Ft - F0) 预测当前相位位置，在预测点前后约 0.45 个周期内选择最近的合格上升沿过零点。
  9. 候选过零点还需要满足包络能量以及过零前后正、负摆幅要求，最终选中的 Zx 用于声时计算。
扫波与置零：进入扫波模式会清除该通道旧的运行期锚点并重新捕获当前工件。 扫波最多保留 5 组包络、过零点和周期结果：F0/Z0 从声时最接近中位数的真实帧中成对选取，T0 取这些有效周期的中位数。 置零时，系统将当前包络位置、上升沿过零时间和稳定周期共同保存为后续监测参考。 更换螺栓后应重新扫波并重新置零；只换螺栓而沿用旧 F0/Z0/T0，可能选择到错误周期。

适用场景与失败条件

适用场景
  • 多通道长期监测，希望结果落在稳定的上升沿过零点。
  • 载荷或温度变化使回波相对置零波形跨周期移动。
  • 回波幅值、耦合或增益有一定变化，但主回波包整体仍可识别。
失败条件与风险
  • 信号幅值未达到有效要求时，本帧无有效测量结果。
  • 未找到有效主回波、包络前沿或合格上升沿时，本帧无有效测量结果。
  • 主回波不足 3 个稳定周期时，系统改用探头配置周期；配置频率也无效时无法完成测量。
  • 强干扰回波能量超过目标回波时，可能选错主回波但仍产生测量数值。
  • 探头频率配置错误、窗口截断前沿，或换螺栓后未重新扫波/置零，可能造成错周期。

2. 动态特征：包络前沿阈值

动态特征法更关注回波包络的前沿。它先检测主回波区域，再计算并平滑 Hilbert 包络， 取主回波包络最大值的固定比例作为动态阈值，最后使用包络首次越过阈值的位置作为结果。

工作过程

  1. 首先检查信号是否达到有效幅值要求；信号过弱时，本帧结果判定为无效。
  2. 去除直流偏置并识别有效回波区域。
  3. 优先选择第一个有效周期数不少于 3 的区域，否则取第一个区域。
  4. 计算 Hilbert 包络并平滑，取主回波内包络最大值。
  5. 动态阈值取主回波包络峰值的 30%。
  6. 在主回波内寻找包络首次越过动态阈值的位置，并通过插值提高时间分辨率。
动态特征法直接把包络越过动态阈值的位置作为测量点，Mx/My 表示该阈值交点。 该方法不再寻找真实波形的上升沿过零点，因此其界面标识与自动法不同。

适用场景与失败条件

适用场景
  • 主回波前沿清楚、包络形状稳定，关注回波到达位置而非固定相位点。
  • 希望避免人工配置绝对幅值阈值，并允许整体幅值按比例变化。
  • 对相位级精度要求低于自动法，但希望算法简单、响应直接。
失败条件与风险
  • 信号幅值未达到有效要求时，本帧无有效测量结果。
  • 没有找到有效回波区域、包络峰值或包络阈值交点时，本帧无有效测量结果。
  • 目标回波前存在较强干扰时，可能因“优先第一个有效区域”而选错回波。
  • 包络形状随增益、耦合或频谱明显变化时，30% 前沿位置会漂移，结果可能变化但不一定报错。

3. 阈值：过阈值 + 上升沿过零

阈值法的定位规则最直观。它先寻找实时波形越过设定阈值的位置，再在该位置附近进行插值， 最终选择阈值点之后的正向上升沿过零点。未设置有效阈值时，系统使用波形正峰最大值的 60% 作为动态阈值。

图示重点：阈值线只用于找到搜索起点 Mx，Mx 不是最终声时。 SDK 会继续向时间轴正方向寻找后续的正向上升沿过零点 Zx，并使用 Zx 计算声时。 正阈值应画在 0 mV 基线上方并寻找上升越阈值；负阈值应画在基线下方并寻找下降越阈值，最终仍取后续正向上升沿过零点。

工作过程

  1. 首先检查信号是否达到有效幅值要求；信号过弱时，本帧结果判定为无效。
  2. 确定阈值：阈值应位于噪声峰值之外，同时保留目标回波在最低幅值工况下的越线裕量；已设置时使用设置值，未设置时使用波形正峰最大值的 60%。
  3. 按阈值正负确定边沿方向：正阈值找上升过阈值，负阈值找下降过阈值。
  4. 若波形没有越过阈值，则本帧测量失败。
  5. 在阈值点附近进行重采样插值，再寻找其后的正向上升沿过零点。

适用场景与失败条件

适用场景
  • 回波极性、幅值和形态稳定，可以给出明确阈值。
  • 现场需要用阈值线直接解释和人工复核测量点。
  • 干扰与目标回波幅值分离明显，目标回波不会长期跌破阈值。
失败条件与风险
  • 信号幅值未达到有效要求，或波形没有越过阈值时，本帧无有效测量结果。
  • 阈值过低可能先命中噪声或前置干扰；阈值过高可能漏检目标回波。
  • 阈值为 0 时按正峰最大值的 60% 自动生成，不适合正峰很弱或以负峰为主的波形。
  • 越过阈值后若没有形成有效的上升沿过零点，应检查波形形态和阈值是否适配。

现场检查要点

自动法看 F0/Z0/T0

确认主回波区域正确，F0/Z0/T0 来自当前螺栓，最终 Zx 稳定落在预测位置附近的上升沿过零点。

动态特征看包络

重点观察包络前沿是否稳定，以及幅值变化时动态阈值交点是否出现明显漂移。

阈值法看配置

确认阈值位于噪声与目标回波之间。阈值过低可能提前命中干扰，过高则可能漏检目标回波。

选型建议：新建多通道长期监测项目优先验证自动法；包络前沿稳定、主要关注趋势且不要求固定相位时可用动态特征法； 波形起始陡峭、幅值裕量充分并需要人工阈值校核时使用阈值法。无论采用哪种方法，正式监测前都应完成静态重复、加载/卸载、 温度影响和重启恢复验证，不能只凭单帧已有数值判断算法已经正确选中目标回波。
