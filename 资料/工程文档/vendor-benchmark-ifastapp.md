# 厂家软件（iFastApp）对标分析

> 来源：`厂家软件/win-x64/`（Avalonia 桌面程序 iFastApp.exe 78MB + WebAPI 文档 + SQLite 配置库 + Word 报告模板），2026-08-18 逆向梳理。
> 目的：回答"和别人家的产品差距在哪"——逐项对到我们的系统，标注 已有 / 部分 / 缺失，给采纳优先级。

## 1. 厂家的核心打法（从数据模型反推）

SQLite `sys.db` 的表结构和设备配置 JSON 暴露了完整功能面：

| 厂家能力 | 证据 | 说明 |
|---|---|---|
| **力值同步采集（AI 通道）** | `u_device.ai_ch`、`AiConfigs`（激励电压 ExcVolt、满量程、AdZero/AdSpan、MultiCalValues 多点校准） | 测力传感器/拉力机直接接设备模拟量输入，**力和声时同步采样**——标定试验时实时画 F-Δt 曲线，这是 F.docx（力标定报告）的来源。标定表最多 128 点（MaxCalCount） |
| **扭矩-转角法（角度编码器）** | `u_device.angle_ch`、`AngleConfigs`（CountsPerR=1440、方向） | 转角法拧紧试验（TA.docx 报告模板），编码器直连设备 |
| **试验模式** | `u_test`（name、cal_file、test_rs_json）、Tpl/Test 四种模板 F/T/TA/TF | 标定即"试验"：连续同步采集 → 曲线 → 标定文件 → 一键 Word 报告 |
| **材料库** | `u_spec`（velocity、temp_coef、acoustic_coef、elastic_modulus、yield_strength） | 按材料预设声速/温度系数/**声弹系数**/弹模/屈服，建档选材料即带全参数 |
| **螺栓规格库** | `u_bolt_info`（公称直径、螺距、夹持长度、连接方式、上下限、材料等级） | 规格预设复用 |
| **数据平滑** | `u_device.data_smoothing`、`TimeAvg`(16/32 次平均) | 设备/软件侧滑动平均去噪，显示更稳 |
| **温度模型** | `TempTauProfile`、MinTemp/MaxTemp | 温度补偿带 tau（热惯性）曲线档位 |
| **模拟量输出（AO）** | `AoConfigs`：ΔTOF→电压/电流换算表（千点 CalibrationTable）+ RefEchoTime | 把预紧力以 4-20mA/电压输出给 PLC/DCS——老工控集成路径 |
| **北向转发** | Modbus TCP Server / MQTT（data+wave 双 topic）/ HTTP Post | 三种工业北向，可选周期 |
| **对外 WebAPI** | webapi.html：仅 `/api/configs、/api/devices、/api/results、/api/warnings` | **很薄**——只有数据导出级别，无管理面 |
| **Word 报告模板引擎** | Tpl/*.docx + TemplateGuide（{{...}} 占位符、动态行列、统计行） | 用户可自制模板 |

## 2. 对标结论：差距集中在"标定试验闭环"，我们的强项他们没有

**厂家强、我们缺/弱：**

| # | 差距 | 我们现状 | 采纳建议 | 优先级 |
|---|---|---|---|---|
| 1 | **力值同步采集标定**（AI 通道接测力传感器，力与声时同步） | 今日已加 measuredForceN 力值直标（人工读数逐点录入）——是厂家方案的手动版 | 问厂家 SDK 是否暴露 AI 通道读数；能拿到就把"逐档手录"升级为"连续同步采集+自动分档" | 高（有拉伸机的实验室场景） |
| 2 | **材料库/规格库**（选材料自动带声速/温补/声弹/弹模/屈服） | 每颗螺栓手填规格，缺声弹系数字段 | 建 `material_specs` 表 + 建档下拉选择；缺省库预置 42CrMo/35CrMo/40Cr 等常用牌号 | 高（直接减少配错规格→超范围拒算） |
| 3 | **显示层滑动平均**（TimeAvg 16/32） | 实时页显示原始逐条值 | 实时预紧力页加"N 次平均"开关（纯前端即可做） | 中 |
| 4 | **温度 tau 模型**（热惯性档位） | 线性温补系数一个值 | 现场温度变化慢，先不做；标定环境温度记录已有 | 低 |
| 5 | **AO 模拟量输出 / Modbus Server** | 无（我们北向是 REST/推送） | 客户要接 PLC 时再做 Modbus TCP Server（库现成），AO 是硬件功能跟厂家确认 | 按需 |
| 6 | **转角法试验** | 无 | 需要角度编码器硬件，非监测主业 | 暂不做 |

**我们强、厂家没有：**
- 资产层级（项目/机组/部位/螺栓）与在线监测语义（在位/告警/验收/审计/两级档案）——厂家是"仪器软件"，我们是"监测系统"
- 完整管理 API（厂家 WebAPI 只有 4 组只读导出）
- 标定护栏体系（稳定性门、零载核对、基线隔离、会签）——厂家把准确性交给"力值同步采集"这个硬件优势，软件护栏基本没有
- 相关法声时诊断（今日新增，厂家配置里未见互相关痕迹）
- 热插拔识别 / 探头扫描 / 串扰排除

## 3. 已直接采纳的（今日）

- 力值直标（measuredForceN）——厂家 F 试验的人工版
- 相关法声时 + 亚采样精化——对标"竞品声时更稳"
