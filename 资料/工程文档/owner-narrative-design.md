# 业主大屏「本期说明」

> 状态：服务端按固定句式拼这段话（2026-10-19 去掉大模型）。
> 范围：只在 `src/BoltPreload.Monitor`。桌面端 `FxMonitor` 没有这段，也没有入口。
> 读者：业主。总览、机组结构、实时监测仍只有状态词和数字；说明只出现在「报警中心」和「统计报告」。

## 1. 业主看到什么

报警中心：统计条下面、事件列表上面，一块和现有 `.panel` 同风格的「本期说明」。

统计报告：时间芯片下面、健康环上面，同一块。两页文案相同，因为数据范围相同（全场 + 当前芯片）。

一块里只有一段话，按这个顺序：

1. 现在：监测多少颗，正常、偏低、松动、需要现场复核各多少。还不能判断松紧、暂时没有新数据，只有颗数大于 0 才写。健康率只有服务端算出来才写。
2. 点名：松动优先，其次偏低，其次需要现场复核，再次还不能判断松紧。最多 8 颗，写法是「F05 · 中段法兰 · 螺栓 24」。有力值就写页面上那一种：在役锚定写「估算预紧力」，自由状态置零写「预紧力」；锚定且该路没有额定时，写「较安装时变化」，不把它说成预紧力。有额定才写额定和所占百分比。该测点在本区间有最低、最高才写这两个数。超过 8 颗时，下一句写还有几颗没有逐一点名。
3. 这段时间：新出现的松动、恢复正常、读数基准更新、需要复核的次数。
4. 收束：当前有需要现场复核的，最后一句只写「需要现场复核」。不写原因，不写怎么处理。

总览、机组、实时监测、运维详情不加这段话。

## 2. 不做什么

- 不调用模型，不读 `ai.json`，说明接口不发出站 HTTP。
- 不在测量回调里做这段汇总。
- 不把波形、声时、标定文件名、斜率、设备地址、`farm.json` 写进这段话。
- 不做自由提问。
- 不在桌面端加入口。

## 3. 材料

数字在进句子之前就算完。`OwnerBrief.Compose` 先收成一份材料，`Narrative.Speak` 再填进第 1 节的句式。

### 3.1 现在

采集回调在现有 `Health.Judge` 之后，把这一路已经算好的结果写进 hub 上的快照（机组、通道、状态、估算预紧力、较基线变化、写入时刻）。这是赋值，不是再算一遍。

说明接口读取快照时：

- 超过 60 秒没更新的测点，状态改为「暂时没有新数据」，与 `STALE_MS` 一致。
- 健康率与 `updateReport` 同一公式：全场有标定且至少一处额定值时，`正常颗数 / 监测颗数` 取整；否则材料里不放健康率字段。
- 位置：`F` + 两位机组号 + 法兰名。`FlangeCal.Bolts` 有这一路才加「螺栓 N」。没有法兰归属的写「未分配」，不写通道号。法兰名里若带上下面这些运维字，这一截名字不写。

### 3.2 这段时间

复用 `HistoryStore.QueryReport` 的最低、最高、平均。事件不把 `QueryEvents` 的原文送出去，只在库里按 `to_h` 计数：

| 计数字段 | 来源状态 |
|---|---|
| `becameLoose` | `to_h = loose` |
| `recovered` | `to_h = ok`，且 `from_h` 是偏低或松动 |
| `readingReset` | `to_h = rezero` |
| `needsReview` | `to_h` 属于检测异常、探头无信号、基线失配、基线可疑 |

`note` 列不进入材料。区间平均留在材料里，句子只引用最低和最高。

### 3.3 点名清单

从「现在」里挑状态不是正常、不是离线的测点，按松动、偏低、需要现场复核、还不能判断松紧排序，最多 8 条。多出来的只给一个剩余颗数。每条带位置、业主状态词、当前力值或变化量、额定、占额定的百分比、以及该测点在本区间的最低/最高/平均。没有额定就不放百分比。未标定导致没有力值的，不放力值字段。

### 3.4 业主用词

| 内部状态 | 句子里的词 |
|---|---|
| ok | 正常 |
| warn | 偏低 |
| loose | 松动 |
| fault、noprobe、shift、badbase | 需要现场复核 |
| uncal、unrated | 还不能判断松紧 |
| offline，或快照超过 60 秒 | 暂时没有新数据 |
| rezero（只出现在区间计数） | 读数基准更新 |
| pending | 不进入材料（不是在测螺栓） |

句子里不出现这些字：通道、CH、标定、回波、声时、置零、纳秒、探头、增益、ucf。

## 4. 接口与页面

`GET /api/narrative?range=24h|7d|30d`

与 `/api/report` 一样，局域网可读，只读。

成功时 `200`，`{ "range": "7d", "text": "…", "asOf": <unix ms> }`。页面用 `textContent` 写入段落，标题右侧写「截至」加这个时刻。请求失败或没有正文时，说明块隐藏，环图、明细、事件列表照常。

页面在进入报警中心、进入统计报告、切换两处时间芯片，以及这两页自己的 15 秒刷新时各请求一次。不挂到每秒一次的全场刷新上。

`index.html` 两处各有一个 `.panel`。`style.css` 只加说明段落的字号和行距，面板沿用现有 `.panel`。

## 6. 验收

1. 报警中心和统计报告在同一时间范围下是同一段话，标题右侧的时刻与接口 `asOf` 一致。
2. 健康率、颗数与报告页一致；点名螺栓的力值与当前显示一致。全场未标定：说明里没有健康率，也没有力值。
3. 当前有需要现场复核的螺栓时，最后一句是「需要现场复核」，前面不写原因和处理办法。
4. 超过 8 颗要点名时，只写前 8 颗，并写剩余颗数。
5. 说明接口不发出站请求。采集和历史写入与这段话无关。
